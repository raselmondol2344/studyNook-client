# StudyNook

## Overview

StudyNook is a library room booking platform designed for students. It allows users to find, explore, and book study rooms for specific time periods based on their academic needs. The platform provides a smooth and user-friendly experience for discovering available rooms, managing bookings, and listing study spaces.

---

## Features

### Homepage
- Attractive hero banner section.
- Displays the latest 6 available study rooms.
- Quick access to room details and booking options.

### All Rooms
- Browse all available study rooms.
- Search rooms by keywords.
- Filter rooms based on category, capacity, or other criteria.
- Responsive room listing layout.

### Room Details
- View complete information about a selected room.
- Room images, description, pricing, capacity, and other details.
- Book a room for a specific date and time.

### My Bookings
- Displays all rooms booked by the logged-in user.
- Easy booking management.
- Personalized booking history.

### Add Room
- Authenticated users can add new study rooms.
- Submit room information, pricing, images, and descriptions.

### My Listings
- Shows all rooms created by the logged-in user.
- Manage personal room listings.
- Update or delete room information.

### Authentication
- Secure user authentication using BetterAuth.
- User session management.
- Protected routes for authorized users.

### Responsive Design
- Fully responsive across mobile, tablet, and desktop devices.
- Modern and clean user interface.
